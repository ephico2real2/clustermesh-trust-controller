# ADR-005: Node agent design

**Status:** Proposed; updated from static source review on 2026-10-23. Architecture/security approval pending.

## Decision direction

Retain hub/per-cluster Go controllers and a lightweight node DaemonSet for inventory, authenticated generation/digest ACKs and bounded probes. Cilium owns packet enforcement. Evaluate minimal Hive observation hooks supporting the agent.

## Source evidence and gaps

V02/V03/V11 show Cilium already owns endpoint inventory, enrollment, ZDS ACKs and the per-node proxy. A second enroller would duplicate authority. No stable external protection or bundle-consumption API was verified.

## Alternatives and trade-offs

Compare the DaemonSet plus a versioned Cilium observer with a Hive-only observer, measuring privilege and footprint. Retain the lightweight DaemonSet target while evaluating duplication. Avoid unrestricted StateDB/debug and host filesystem access.

## Acceptance gates

Specify authentication, UID/generation/digest binding, freshness, RBAC and mounts. Disconnected/stale agents cannot report fresh protection. No signing-key access, independent iptables/eBPF mutation, identity minting or second traffic proxy.

Evidence IDs refer to the [Cilium v1.20.4 audit](../../research/SOURCE_AUDIT.md). No runtime capability is claimed. Mark Accepted only after explicit architecture/security approval.
