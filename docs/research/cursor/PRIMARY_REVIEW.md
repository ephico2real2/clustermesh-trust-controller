# Primary review of Cursor's first Extra High design

Status: changes required. The proposal is not accepted or applied.

1. **Preserve full authorization semantics.** The proposed `matches_for_anchors` checks only identity clauses with nested `any` calls, ignoring ports, addresses, namespaces and other fields, and appears to flatten the existing Boolean structure. A permitted principal must NOT be sufficient to satisfy a rule whose application port or another AND condition denies the request. Do not replace the actual matcher with a principal-only helper. Keep TLS issuer verification separate from policy compilation and retain the existing full rule evaluator. Any supported-profile restrictions must reject unsupported policy at admission/compilation, not silently skip its constraints. Provide actual tests: same exact principal on an allowed port passes; same principal on forbidden port fails; mixed principal/namespace/port AND constraints remain; explicit DENY wins; label-specific policy cannot become a broader SA grant.

2. **Withdrawal is authoritative even if SPIRE is stale or unavailable.** The proposed text says a removed-pin profile plus an old SPIRE bundle can fail refresh while retaining the previous generation. This would retain the withdrawn issuer. A valid authoritative withdrawal must immediately fence the old generation and drain its active/pooled transports before an unavailable or rejected replacement bundle can postpone that action. Accept conservative deny/unavailable state until corrected data arrives. Never resurrect a withdrawn pin from retained bundles, reconnect versions or old snapshots. Provide executable wrong-order, partition, stale-bundle, withdrawal and corrected-recovery tests.

3. **Expiry affects retained connections too.** Checking pin validity only on new handshakes does not retire a long-lived HTTP/2 pool or active flow. Add an expiry/freshness deadline mechanism that invalidates admission and cancels relevant old connections at the deadline even if no successful reload occurs. Test with deterministic time and a real retained connection watcher path; use socket-level integration for the runtime gate. No indefinite last-known-good trust after authority expiry.

4. **TLS 1.3 packet evidence.** Do not promise a plaintext certificate extract from an ordinary TLS 1.3 packet capture. Correlate encrypted HBONE/TLS packet metadata and absence of the application canary with authenticated proxy identity/policy logs and independently exported PUBLIC chain/issuer/SPKI evidence. Do not introduce session-key logging or private-key capture.

5. **Complete implementation/test files.** The first document lists required imports, methods and watch/pool call sites without supplying all code. The human explicitly requires complete code snippets/patches plus executable tests in a document the primary copies. Narrow a code increment if necessary, but do not describe incomplete scaffolding as a finished change. Label all deferred integration gates honestly.

Keep the current ClusterMesh guard closed and the full-scope request in FULL_CODE_REQUEST.md. This review must be addressed before primary acceptance. Read the exact current interfaces, preserve existing matching and lifecycle semantics, and include negative/recovery tests for each correction.
